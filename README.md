# asgerami.com

My personal portfolio: projects, experience and writing.

Live at [asgerami.com](https://asgerami.com).

## Built with

- [Astro](https://astro.build), a fully static site
- [Tailwind CSS](https://tailwindcss.com) for styling
- TypeScript, with plain browser scripts for the interactive parts (no frontend framework)
- Geist, Geist Mono and Instrument Serif fonts, self-hosted
- A canvas globe drawn from NASA's Blue Marble and Black Marble imagery
- Hosted on [Vercel](https://vercel.com)
